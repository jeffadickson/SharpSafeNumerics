## SIMD prototype measurements and production support

The benchmark-only Vector256<int> batch addition prototype writes a status and
either the exact result or zero for each lane, validates output aliasing and
lengths, and has scalar fallback/tails. Read-only input buffers may alias.
BigInteger tests exercise vector-width neighbors and both dispatch modes.
Independent review found stale output buffers could hide missing vector writes;
each mode now receives fresh poisoned buffers. A deliberate removal of vector
stores caused six tests to fail; restoring the stores returned all 11 tests green.

BenchmarkDotNet 0.15.8 InProcessEmit ShortRun (three warmups/measurements, one launch),
Intel Core i5-10505, Windows 11 10.0.26300.9974, .NET 11.0.0 x64 RyuJIT x86-64-v3:
